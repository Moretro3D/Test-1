TAMAPOKE MORETRO — JOHTO V5

Cette version étend l'architecture du jeu de 151 à 251 Pokémon.

Inclus :
- Pokédex 001 -> 251.
- 100 entrées Johto #152-251 avec types et stats.
- Noms français Johto.
- Bitmap de sauvegarde agrandi de 19 à 32 octets.
- Migration compatible avec les anciennes sauvegardes 151.
- Rencontres/œufs peuvent utiliser les espèces Johto.
- Évolutions Johto simples + branches Kanto/Johto principales.
- Mentali/Noctali via lien élevé + heure du RTC.
- Chargeur SD déjà compatible avec les fichiers p152.bin ... p251.bin.
- GitHub Actions télécharge et empaquette automatiquement les sprites Johto
  depuis PMD SpriteCollab lors du premier build, puis les met en cache.
- thumbs.bin régénéré pour 251 Pokémon.
- sprites.pak reconstruit Kanto + Johto.

IMPORTANT :
Le premier build GitHub sera nettement plus long car il doit récupérer et
convertir les sprites #152-251 (normal + shiny). Les builds suivants utilisent
le cache GitHub Actions.

Version : 1.30.0-moretro-johto-v5
