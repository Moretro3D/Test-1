POKETAMA — CUSTOM LIQUID SHOPIFY

Ce bloc affiche la page PokeTama dans Moretro3D.fr sans ajouter de header
ni de footer. Le thème Shopify conserve automatiquement les siens.

Installation dans Shopify :
1. Créer une page nommée PokeTama avec l'URL /pages/poketama.
2. Dans l'éditeur du thème, ouvrir le modèle de cette page.
3. Ajouter une section « Liquid personnalisé ».
4. Copier tout le contenu de poketama-custom-liquid.liquid dans la section.
5. Enregistrer.

La page embarquée provient de :
https://moretro3d.github.io/Test-1/shopify.html

Le fichier shopify.html doit donc être publié sur GitHub avec la V9.43 avant
d'afficher la page Shopify.
